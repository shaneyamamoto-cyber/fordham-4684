Bathroom

Measured bathroom design suite: a 2D multi-view elevation planner that locks geometry, a 3D model of the locked layout with OBJ/GLB export, a material look book, and a fixture combo picker. Built to keep AI image generators on the real floor plan.
← All projects
01

Elevation Planner

Edit shell, fittings and materials in measured 2D elevation + plan views. Drag with live inch readouts, group, lock, undo/redo, and lock named versions.
02

Bathroom 3D

Renders the locked version as a real three.js model. Frame the plate shot, export OBJ+MTL or GLB for image-gen handoff.
03

Look Book

59 real material cutouts (tile, wood, metal, mirror, textile) and the shaped hardware icon library, browsable independent of the plan.
04

Fixture Options

Combo-pick a fixture and finish package: toilet, mirror, tap, showerhead, lighting — 41 options across 5 categories.
Note on dependencies: the planner and look book run on the dc-runtime (support.js) which loads React from unpkg, and the 3D viewer loads three.js from unpkg via an import map — so these pages need internet access. The sauna project is fully self-contained; vendoring these deps into platform/vendor/ is on the roadmap (see docs/ARCHITECTURE.md). Geometry source of truth and AI-render constraints live in reference/.
