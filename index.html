Measured Design · 2D Plans · 3D Builds

YamaZina Design Platform

One platform, independent projects. Each project pairs a quick, accurate 2D measured planner with a technical 3D build of the same design — both views read and write one shared design state through the platform core, so an edit in either is the design. Versions, budget, units and persistence are platform services, not per-project forks.
